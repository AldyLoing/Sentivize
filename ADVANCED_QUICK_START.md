## 🎯 Mode Selection

Saat membuka aplikasi, pilih mode yang sesuai:

### 🚀 Standard Mode (Fast)
- **Speed:** Very Fast (< 1 second per document)
- **Accuracy:** Good (70-80%)
- **Use for:** Initial screening, large batches
- **Models:** TF-IDF + VADER (lightweight)

### 🧠 Advanced Mode (Deep)
- **Speed:** Slower (3-5 seconds per document)
- **Accuracy:** Excellent (85-95%)
- **Use for:** Final selection, detailed analysis
- **Models:** BERT + Transformers (AI-powered)

**Recommendation:** Start with Standard, switch to Advanced for final candidates.

## 📄 Using Advanced CV Analyzer

### Step 1: Select Mode
1. Open app: `streamlit run app.py`
2. In sidebar, select **"🧠 Advanced Mode"**
3. Choose **"📄 Advanced CV Analyzer"**

### Step 2: Configure Options
In sidebar:
- ✅ **Mock Mode:** For fast testing (recommended first time)
- ✅ **Deep Parsing:** Extract detailed CV sections
- ✅ **Personality Assessment:** Analyze soft skills
- ✅ **Cultural Fit Analysis:** Check value alignment

### Step 3: Upload CVs
- Drag and drop PDF, DOCX, or TXT files
- Can upload multiple files for batch analysis
- Ensure CVs are text-readable (not scanned images)

### Step 4: Enter Job Criteria
Use **Quick Templates** or write custom criteria:

**Example Good Criteria:**
```
3+ years experience in full-stack web development
Proficient in Python (Django/Flask) and JavaScript (React/Vue)
Experience with RESTful APIs and microservices
Bachelor's degree in Computer Science or related field
Strong problem-solving and communication skills
Experience with cloud platforms (AWS/GCP) is a plus
```

**Quick Templates Available:**
- 👨‍💻 Software Engineer
- 📊 Data Analyst
- 🎨 UI/UX Designer

### Step 5: Analyze!
Click **"🚀 Analyze CVs"** and wait for results.

### Step 6: Review Results

**Summary Table:**
- Quick comparison of all candidates
- Color-coded relevance scores
- Contact information at a glance

**Visualizations:**
- Relevance ranking bar chart
- Soft skills radar charts
- Relevance breakdown components

**Detailed Analysis (Per Candidate):**
- **Profile Tab:** Work experience, education, skills
- **Strengths Tab:** Top 3-5 key strengths with evidence
- **Breakdown Tab:** Score components, soft skills radar
- **Assessment Tab:** Professional HR-style assessment
- **Contact Tab:** All contact info, certifications, awards

**AI Insights Include:**
- 🎯 Relevance Score (0-100%)
- 💪 Key Strengths (with reasoning)
- ⚠️ Potential Areas
- 📊 Relevance Breakdown (by component)
- 🎭 Soft Skills Assessment
- 🧠 Professional Assessment (narrative)
- 📝 Overall Recommendation

### Step 7: Download Results
Click **"📥 Download Detailed Analysis (Excel)"**

Excel includes:
- Summary sheet (all candidates)
- Detailed analysis sheet
- Criteria sheet

## 💡 Tips for Best Results

### CV Analysis Tips:

1. **Be Specific in Criteria**
   ```
   ✅ Good: "Python with Django, 3+ years, AWS experience"
   ❌ Vague: "Programming skills"
   ```

2. **Use Transformers Mode for Final Selection**
   - Initial screening: Mock Mode (fast)
   - Shortlist 5-10 candidates
   - Final analysis: Transformers Mode (accurate)

3. **Check All Tabs**
   - Don't just look at scores
   - Read AI reasoning and evidence
   - Review soft skills assessment

4. **Compare Side-by-Side**
   - Upload 5-10 CVs together
   - Use visualizations for comparison
   - Sort by different metrics

### Employee Analysis Tips:

1. **Focused Themes**
   ```
   ✅ Good: "environmental sustainability, renewable energy"
   ❌ Vague: "good person"
   ```

2. **Provide Bio/Description**
   - Better insights with more text
   - Social media posts help
   - Quality over quantity

3. **Review Behavioral Profile**
   - Personality traits show work style
   - Value alignment shows fit
   - Green/red flags are important

4. **Use Clustering**
   - Find groups with similar values
   - Identify diversity gaps
   - Build balanced teams

## 🎓 Understanding AI Outputs

### Relevance Score (0-100%)
- **75-100%:** Excellent match - HIGHLY RECOMMENDED
- **60-74%:** Good match - RECOMMENDED
- **40-59%:** Partial match - CONSIDER
- **0-39%:** Poor match - NOT RECOMMENDED

### Confidence Score (0-100%)
How confident the AI is about its analysis:
- **80-100%:** Very reliable (complete data)
- **60-79%:** Reliable (good data)
- **40-59%:** Moderate (limited data)
- **0-39%:** Low (very limited data)

### Personality Traits (0-1 scale)
- **0.75-1.0:** Very High
- **0.60-0.74:** High
- **0.40-0.59:** Moderate
- **0.20-0.39:** Low
- **0.0-0.19:** Very Low

### Value Alignment (0-1 scale)
- **0.70+:** Strong alignment
- **0.50-0.69:** Good alignment
- **0.30-0.49:** Moderate alignment
- **0.0-0.29:** Weak alignment

## 🐛 Common Issues

### Issue: "Models not loading"
**Solution:**
```bash
# Reinstall transformers
pip install --upgrade transformers sentence-transformers

# Or use Mock Mode instead (no models needed)
```

### Issue: "Analysis too slow"
**Solution:**
- Switch to Mock Mode
- Reduce batch size
- Disable social media scraping
- Use Standard Mode

### Issue: "Out of memory"
**Solution:**
```bash
# Install CPU-only PyTorch (smaller)
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### Issue: "Low confidence scores"
**Solution:**
- Provide more complete CV/employee data
- Add bio/description text
- Include social media links
- Use longer, detailed criteria

### Issue: "Scores seem off"
**Solution:**
- Use Transformers Mode for better accuracy
- Review AI reasoning (not just scores)
- Check if criteria matches CV content
- Ensure data quality (readable text)

## 📊 Example Workflow

### Hiring Workflow:

1. **Collect 50 CVs** for Software Engineer position

2. **Initial Screening (Standard Mode)**
   - Upload all 50 CVs
   - Use basic criteria
   - Get results in ~5 minutes
   - Filter: Keep top 15 (relevance > 60%)

3. **Deep Analysis (Advanced Mode)**
   - Upload top 15 CVs
   - Use detailed criteria with requirements
   - Enable all analysis options
   - Review detailed insights

4. **Review Top 5**
   - Read professional assessments
   - Check strengths and fit analysis
   - Review soft skills radar
   - Compare side-by-side

5. **Decision**
   - Invite top 3-5 for interview
   - Use AI insights to prepare interview questions
   - Check red flags during interview
