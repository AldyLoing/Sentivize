## 🔍 FAQ - Frequently Asked Questions

### Q: Dokumentasi mana yang harus saya baca dulu?
**A**: Tergantung tujuan Anda:
- **Coba cepat**: QUICK_START.md
- **Install lengkap**: INSTALL.md → README.md
- **Development**: ARCHITECTURE.md → API_BLUEPRINT.py

### Q: Berapa lama waktu yang dibutuhkan untuk setup?
**A**: 
- **Quick test** (Mock Mode): 5-10 menit
- **Full setup** (Transformers): 20-30 menit (termasuk model download)

### Q: Apakah saya perlu GPU?
**A**: Tidak, aplikasi bisa jalan di CPU. GPU hanya membuat lebih cepat.

### Q: File apa yang perlu saya edit untuk kustomisasi?
**A**: 
- **Settings**: `config.py`
- **UI**: `app.py`
- **Business logic**: `analyzer.py`

### Q: Bagaimana cara update aplikasi?
**A**: 
```powershell
git pull  # atau download ulang
pip install --upgrade -r requirements.txt
```

### Q: Di mana model AI disimpan?
**A**: `~/.cache/huggingface/` (Windows: `C:\Users\YourName\.cache\huggingface\`)

### Q: Apakah data saya aman?
**A**: Ya, semua proses lokal kecuali web search (opsional). Lihat disclaimer di README.md

### Q: Bagaimana cara report bug atau request feature?
**A**: Dokumentasikan issue Anda dengan:
- Error message lengkap
- File `test_simple.py` output
- Python version & OS
- Steps to reproduce
